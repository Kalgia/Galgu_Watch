■ Galgu Watch — 작업시간 스탑워치
==================================

작업/공부 시간을 재고, 자동 스크린샷과 작업일지로 하루를 기록하는 프로그램입니다.
설치 필요 없음 — GalguWatch_v1.1.exe 같은 실행 파일 하나가 전부입니다.
(파일 이름의 숫자가 프로그램 버전입니다)

【시작하기】
1. 실행 파일(GalguWatch_v○.○.exe)을 원하는 곳에 두고 더블클릭 (바탕화면도 OK)
   ※ 첫 실행은 내부 구성 요소를 푸느라 몇 초 걸릴 수 있어요
   ※ "Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] → [실행]
      (개인 제작 프로그램이라 서명이 없어서 나오는 안내입니다)
2. 화면 우상단에 작은 타이머(오버레이)가 뜹니다
3. ▶ 시작 / ⏸ 일시정지(잠깐 쉴 때) / ⏹ 작업 마무리(오늘 끝!). 드래그로 위치 이동.
   - 시작·마무리 때 채널에 응원 메시지가 자동으로 올라가요 (⚙️ 설정에서 이름 변경·끄기 가능)
   - 일시정지·자리비움은 조용히 기록만 멈춥니다

【주요 기능】
- 측정 중에만 10분마다 자동 스크린샷 (간격·저장 폴더는 ⚙️ 설정에서 변경)
- 오버레이 📷 버튼: 지금 화면 즉시 캡처 / ✂ 버튼: 드래그한 영역만 캡처
- 🎯 목표 탭(캘린더 창): 목표 추가·달성 체크, 목표 날짜를 정하면 캘린더에 🎯로 표시
- 트레이 아이콘(작업표시줄 오른쪽 초록/회색 점) — 더블클릭: 시작·정지 / 우클릭: 메뉴
- "캘린더 열기": 달력에서 날짜별 기록·스크린샷·작업일지 확인 (일지는 자동 저장)
- 5분간 키보드·마우스 입력이 없으면 자동 정지 (자리비움 보호)
- PC 절전·화면잠금 시 자동 정지, 강제 종료돼도 기록 자동 복구
- 디스코드가 켜져 있으면 내 프로필에 "Galgu Watch — 작업 중"이 실시간 표시
  (안 보이면: 디스코드 설정 → 활동 개인정보 → "현재 활동을 상태 메시지로 표시" 켜기)

【디스코드 채널에 일지 올리기】
1. 같이 쓰는 채널에서 공유받은 웹훅 URL을 복사
2. 캘린더 창 우상단 ⚙️ 설정 → "디스코드 연동"의 웹훅 URL 칸에 붙여넣고 저장
3. 날짜 클릭 → 📤 공유 → 올릴 스크린샷 선택 → "📨 디스코드 채널로 올리기"

【데이터 위치】
기록·스크린샷·일지는 전부 내 PC에만 저장됩니다 (외부 전송 없음):
C:\Users\(사용자이름)\AppData\Local\GalguWatch
실행 파일을 지워도 이 데이터 폴더를 지우지 않으면 기록은 남습니다.
새 버전 실행 파일로 바꿔도 기존 기록이 그대로 이어집니다.

【종료】
트레이 아이콘 우클릭 → 종료
